# QM Vježbanje

Aplikacija za vježbanje i učenje iz kolegija Kvantitativne metode odlučivanja u poslovnoj praksi (Libertas).
Lekcije, nasumični zadaci s postupkom, kviz "Prepoznaj tip", simulacija ispita, formule i Z-tablica.

Radi i kao mobilna aplikacija (PWA). Nema build koraka: otvori `index.html` ili objavi mapu na Vercelu / GitHub Pages.

Live: https://qm-vjezbanje.vercel.app
